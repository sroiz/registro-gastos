# registro-gastos

Script de Python para registrar y organizar gastos personales desde la terminal.

## ¿Qué hace?
- Registra gastos con fecha, categoría, descripción y monto
- Guarda los datos en un archivo `.csv`
- Muestra un resumen de gastos totales por categoría
- Muestra la lista completa de gastos registrados

## Categorías disponibles
- Comida
- Transporte
- Escuela
- Casa
- Otros

## ¿Cómo usarlo?
1. Ejecuta el archivo `registro_gastos.py`
2. Elige una opción del menú
3. Los datos se guardan automáticamente en `datos.csv`

## Librerías usadas
- `csv`
- `os`
- `datetime`
